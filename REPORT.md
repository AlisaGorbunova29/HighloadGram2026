# HI1. API Gateway

### Инструкция по запуску:
1) Скачать репозитрий к себе на компьютер
2) Открыть терминал
3) Для установки необходимых для запуска пакетов выполнить команду
```bash
make quick-start
```
4) Запустить бэкенд. Тут есть 2 варианта:
- Можно поднять Web-сервер на 1 инстансе бэкенда и отправлять запросы напрямую:
```bash
make run-backend
```
- Либо поднять 2 инстанса бэкенда и отправлять запросы через NJINX:
```bash
make NGINX-up
```

5) Выполнить один из сценариев тестирования:
- Отправка GET-запроса (напрямую на бэкенд либо через NGINX):
```bash
make GET-backend
```
```bash
make GET-NGINX
```

- Отправка POST-запроса (напрямую на бэкенд либо через NGINX):
```bash
make POST-backend
```
```bash
make POST-NGINX
```

- Демнострация балансировки:
```bash
make demonstration-balance:
```

- Нагрузочное тестирование:
```bash
make ab-test
```
