#  Инструкция по запуску

1. Скачать репозиторий на свой компьютер
2. Создать и активировать виртуальное окружение
```bash
python -m venv venv
source venv/bin/activate
```
3. Установить необходимые пакеты:
```bash
pip install -r requirements.txt
```
4. Ввести данные своей почты, с которой будет осуществляться отправка писем.

Файл worker.py:
```python
SMTP_SERVER = "smtp.gmail.com"
SMTP_PORT = 587
EMAIL_ADDRESS = "адрес_почты_с_которой_будут_отправляться_письма@gmail.com" 
EMAIL_PASSWORD = "ваш_пароль_приложения"
```
Для получения пароля приложения нужно:

* Зайти в gmail-почту. 
* Перейти в раздел "Безопасность". 
* Найти "Пароли приложений".
* Создать новый пароль для работы highloadGram.
* Скопировать его и добавить в worker.py

5. Поднять docker c RabbitMQ и Redis:
```bash
docker-compose up -d
```

6. Запустить сервис и воркера
```bash
python App.py
python worker.py
```
7. Перейти на http://127.0.0.1:5000

8. По завершению работы:
```bash
docker-compose down
```
