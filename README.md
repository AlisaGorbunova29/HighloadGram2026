## Запуск

* Для запуска приложения введите в терминале:
```bash
docker compose up --build
```
* Зайдите на сайт  http://localhost:3000

- ClickHouse Shard2: localhost:8124

# Общая информация

Так как у меня не получилось прикрутить gRPC-web во втором заданий, то я решила оформить данное домашнее задание как отдельное. В нём можно создавать каналы, добавлять теги и публиковать посты в свои каналы (доступно для админов = создатель канала). Другие пользователи видят все каналы, могут на них подписываться, читать посты и смотреть аналитику (обновляется раз в минуту)

## Архитектура баз данных:

- Так как в тз указано, что количество чтений в каналах сильно больше количество записей и нужно обеспечить эффективный Read-only режим, было принято решение использовать технику репликации. Данные записываются в мастер (Postgres SQL), далее данные копируются в 2 реплики (Postgres SQL) и читаются из реплик.
- Для эффективного поиска по тегу в систему добавлено шардирование по номеру канала (данные одного канала хранятся на одном шарде). И далее на каждом шарде данные отсортированы по (канал, тег, дата публикации), что позволяет более эффективно получать все сообщения одного тега, так как они хранятся как непрерывный кусок на шарде. 
- Аналитика хранится на каждом шарде в отдельной таблице. Так как используется ClickHouse для шардирования и сбора данных для аналитики, то выборка происходит не по строкам, а по столбцам, что ускоряет подсчет статистики.
