# HighloadGram 2.0

## Инструкция по установке и запуску
1) Скачать репозиторий на свой компьютер
2) Открыть в терминал и перейти в папку, в которой находятся файлы из репозитория. Разделить терминал на несколько (один для запуска сервера + n терминалов для запуска n клиентов)
3) Установить все необъходимые зависимости в окружение:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
4) Запустить сервер командой:
```bash
python server.py
```
5) Запустить каждого клиента командой с указанием никнейма пользователя:
```bash
python client.py {username}
```
6) После соединения появится надпись ``{username}: __CONNECT__``. Это будет означать, что пользователь успешно подключен к серверу.
7) Далее можно отправлять сообщения между пользователя в по опрелеленному шаблону: ``{username} {message}``
8) Для отключения от сервера нужно написать команду `quit`
9) Приятного общения!

Демонстрацию работы HighloadGram можно посмотреть в этой же папке.
